## Yi Jing Oracle

Application de consultation du Yi Jing (Livre des Mutations) basée sur la méthode traditionnelle des 3 pièces.

### Fonctionnalités

- Tirage avec 3 pièces virtuelles
- Visualisation des hexagrammes
- Interprétation des lignes mutantes
- Hexagramme de perspective

### Technologies

- Python / Streamlit
- Déployé sur Streamlit Cloud
