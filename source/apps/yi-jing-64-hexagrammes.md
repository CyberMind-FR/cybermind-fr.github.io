## Introduction

Le **Yi Jing** (易經), ou "Livre des Mutations", est l'un des plus anciens textes classiques chinois. Cette application interactive permet d'explorer les 64 hexagrammes et leurs significations.

## Fonctionnalités

### Navigation intuitive
Parcourez les 64 hexagrammes en cliquant sur chacun d'eux pour découvrir :
- Le nom chinois et sa traduction
- La symbolique des trigrammes
- L'interprétation traditionnelle

### Trigrammes de base

Les 8 trigrammes fondamentaux qui composent les hexagrammes :

| Symbole | Nom | Élément |
|---------|-----|---------|
| ☰ | Qián (Ciel) | Métal |
| ☷ | Kūn (Terre) | Terre |
| ☳ | Zhèn (Tonnerre) | Bois |
| ☵ | Kǎn (Eau) | Eau |
| ☶ | Gèn (Montagne) | Terre |
| ☴ | Xùn (Vent) | Bois |
| ☲ | Lí (Feu) | Feu |
| ☱ | Duì (Lac) | Métal |

## Aspects techniques

Cette application utilise :
- **HTML5 Canvas** pour le rendu graphique
- **JavaScript ES6** pour les interactions
- **CSS3** pour les animations fluides
