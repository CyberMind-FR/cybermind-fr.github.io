## 🎨 CyberMind Studio

**Studio de création audiovisuelle et d'art génératif**

CyberMind Studio est un environnement créatif intégré pour la génération d'art audiovisuel, combinant synthèse sonore, visualisation et géométrie sacrée.

### ✨ Fonctionnalités

- 🎵 **Synthétiseur audio** multi-oscillateurs
- 🌀 **Visualiseur** réactif au son
- 🔮 **Géométries sacrées** animées
- 🎬 **Séquenceur** de patterns
- 📹 **Export vidéo** WebM/MP4
- 🖼️ **Export image** PNG haute résolution
- 📱 **PWA** installable

### 🎛️ Modules

| Module | Description |
|--------|-------------|
| **Synth** | Synthétiseur FM/AM avec enveloppes |
| **Visual** | Visualisations audio-réactives |
| **Geometry** | Mandalas et formes sacrées |
| **Sequencer** | Programmation de patterns |
| **Effects** | Reverb, delay, distortion... |
| **Recorder** | Capture audio/vidéo |

### 🌸 Géométries disponibles

- Fleur de Vie
- Sri Yantra  
- Cube de Métatron
- Torus
- Spirale de Fibonacci
- Fractales (Mandelbrot, Julia)

### 🎨 Modes créatifs

1. **Mode Libre** - Création intuitive en temps réel
2. **Mode Guided** - Tutoriels et presets
3. **Mode Performance** - Pour le live et les performances
4. **Mode Meditation** - Ambiances contemplatives

### 💡 Cas d'usage

- Création de visuels pour DJ sets
- Méditation audiovisuelle
- Art génératif pour NFT
- Fond d'écran animé
- Relaxation sonore
