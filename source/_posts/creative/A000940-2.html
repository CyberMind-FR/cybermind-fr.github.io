Cycle → Polygone → Étoile {n/k} 🌐

Même objet mathématique sous trois lampes néon : graphes 🕸️, géométrie 🧭, et étoiles régulières ✴️. Croisements autorisés.

📈 Valeurs (exemples)
a(3)=1 a(4)=2 a(5)=4 a(6)=12 a(7)=39 a(8)=202 a(9)=1219
↺ rotation identifiée ↔ sens identifié ✴️ croisements OK
🧩 Formule (cycles distincts sur Kₙ)
a(n) = (n−1)! / 2 (modulo rotation + inversion)

Interprétation : nombre de cycles hamiltoniens distincts sur le graphe complet Kₙ, donc le même comptage que les polygones (étoilés inclus) sur n points d’un cercle.

🕸️ 1) Version “graphes” : cycle hamiltonien

Kₙ : tout est connecté à tout.

Cycle C = (v0, v1, …, v(n−1)) avec {vi} = {0…n−1} + fermeture (v(n−1) → v0) Même forme ⇔ • rotation du point de départ • inversion du sens
🔁 Cycle visite chaque sommet 1×
↺ Rotation départ arbitraire
↔ Inversion sens identifié
🧭 2) Version “cercle” : polygone (croisé ou non)

On place n points équidistants sur un cercle, puis on trace selon l’ordre du cycle.

Points : p_i = (cos(2πi/n), sin(2πi/n)) Polygone Γ(C) : segments [p(v_i), p(v_{i+1})] avec v_n = v_0
🟩 convexe 🟥 auto-intersections 🟨 même cycle → même forme (rot+rev)
🪄 3) Passage “cycle → polygone”

🧾 Donnée

C = (v0,…,v(n−1))

🧭 Placement

p0…p(n−1) sur un cercle

🧵 Tracé

relier p(v_i) → p(v_{i+1}), fermer
Γ(C) = ⋃ [ p(v_i), p(v_{i+1}) ] Le “dessin” dépend de l’ordre cyclique, pas du point de départ ni du sens.
🌟 4) Notation {n/k} : étoiles régulières

Sous-cas “pas constant” : on avance de k modulo n.

Cycle de pas k : C(n,k) = (0, k, 2k, 3k, …) mod n Condition étoile “pure” : gcd(n,k) = 1 ✅ Symétrie : {n/k} = {n/(n−k)}
ex: {5/1} pentagone ex: {5/2} étoile ex: {7/2}, {7/3}
🧠 Mini-check : “mon cycle est-il un {n/k} ?”
Après rotation/sens : v_{i+1} − v_i ≡ k (mod n) pour tout i

Si le “pas” est constant, tu es sur une étoile régulière {n/k}. Sinon, c’est un cycle hamiltonien général (toujours compté par A000940).
