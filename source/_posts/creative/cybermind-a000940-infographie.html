🧩 Formule
a(n) = (n−1)! / 2 (modulo rotation + inversion)

Interprétation : comptage des cycles hamiltoniens distincts dans le graphe complet Kₙ, équivalent au comptage des "formes" polygonales sur n sommets d'un cercle.

🕸️ Graphes • Cycle hamiltonien

Kₙ : chaque sommet est relié à tous les autres.

Cycle C = (v0, v1, …, v(n−1)) avec {vi} = {0…n−1} + fermeture (v(n−1) → v0) Même forme ⇔ • rotation(C) • reverse(C)
🔁 Cycle visite unique de tous les sommets
↺ Rotation le départ ne compte pas
↔ Inversion sens horaire/anti-horaire identifiés
🧭 Géométrie • Polygone Γ(C)

On place n points équidistants sur un cercle, puis on trace selon l'ordre du cycle.

Points : p_i = (cos(2πi/n), sin(2πi/n)) Polygone associé : Γ(C) = ⋃ [ p(v_i), p(v_{i+1}) ] avec v_n = v_0
🟩 convexe 🟥 auto-intersections 🟨 même "forme" = rot + rev
🪄 Pipeline • Cycle → Polygone

🧾 Entrée

C = (v0,…,v(n−1))

🧭 Placement

p0…p(n−1) sur un cercle

🧵 Tracé

p(v_i) → p(v_{i+1}), fermer
Γ(C) dépend de l'ordre cyclique. Le point de départ et le sens ne changent pas la "forme".
🌟 Étoiles régulières • {n/k}

Sous-cas "pas constant" : on avance de k modulo n.

Cycle de pas k : C(n,k) = (0, k, 2k, 3k, …) mod n Étoile "pure" ⇔ gcd(n,k)=1 ✅ Symétrie : {n/k} = {n/(n−k)}
🧠 Test : "mon cycle est-il un {n/k} ?"
Après rotation/sens : v_{i+1} − v_i ≡ k (mod n) pour tout i

Pas constant = étoile régulière. Sinon : cycle hamiltonien général (quand même compté par A000940).
