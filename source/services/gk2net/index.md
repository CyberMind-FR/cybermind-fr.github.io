## ✨ Création de Marque & Identité

### 🎯 Naming — Trouvez votre nom

```
💡 Idéation → 🔍 Recherche → ✅ Validation → 📝 Dépôt
```

Un bon nom de marque est **mémorable**, **disponible** et **porteur de sens**.

| Service | Description | Livrable |
|---------|-------------|----------|
| 🧠 **Brainstorming créatif** | Séance d'idéation guidée | Liste de propositions |
| 🔍 **Recherche d'antériorité** | Vérification INPI, domaines, réseaux | Rapport de disponibilité |
| 🌍 **Réservation domaine** | .fr, .com, .net, .org, .art... | Domaine sécurisé |
| 📝 **Accompagnement dépôt** | Aide au dépôt INPI | Marque protégée |

#### 💡 Méthodologie Naming

```
1️⃣ Exploration
   └─ 🎯 Définition de l'univers de marque
   └─ 🎭 Valeurs, public, positionnement
   └─ 🌍 Contraintes linguistiques

2️⃣ Création
   └─ 🧠 Brainstorming (50+ pistes)
   └─ ✂️ Sélection (10-15 candidats)
   └─ 🔬 Analyse sémantique & sonore

3️⃣ Validation
   └─ 🔍 Recherche INPI (marques)
   └─ 🌐 Disponibilité domaines
   └─ 📱 Disponibilité réseaux sociaux

4️⃣ Finalisation
   └─ 📋 Shortlist argumentée (3-5 noms)
   └─ 🎨 Premières pistes graphiques
   └─ ✅ Choix final & réservations
```
