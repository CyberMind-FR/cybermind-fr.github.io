A000940 - Dualité Hamiltonienne / Polygonale

Suite A000940

Dualité entre Cycles Hamiltoniens et Polygones Réguliers

a(n) = 1, 2, 4, 12, 39, 202, 1219, 9468, ...   (n ≥ 3)

🔴 Concept 1 : Graphe

Cycles Hamiltoniens sur Kₙ

Un cycle hamiltonien est un chemin fermé qui passe par chaque sommet exactement une fois.

  • Kₙ = graphe complet à n sommets
  • Tous les sommets sont connectés entre eux
  • On compte les cycles distincts (sens horaire = anti-horaire)
a(n) = (n-1)! / 2

On fixe un sommet de départ, (n-1)! permutations des autres, divisé par 2 car un cycle et son inverse sont identiques.

🟢 Concept 2 : Géométrie

Polygones Réguliers à n Sommets

n points équidistants sur un cercle, reliés pour former un polygone (possiblement auto-intersectant).

  • Sommets fixes sur le cercle
  • On choisit l'ordre de connexion
  • Inclut les étoiles {n/k} et formes croisées
Polygones distincts = Cycles / symétrie

Chaque façon distincte de relier les sommets en un cycle fermé donne une figure unique.

🔄 Mutabilité Correspondantielle

Comment transformer une représentation en l'autre :

Graphe → Polygone

Placer les sommets 0, 1, ..., n-1 sur un cercle à angles réguliers (2πk/n).

Tracer les arêtes du cycle dans l'ordre.

Polygone → Graphe

Numéroter les sommets du polygone.

Lire l'ordre de parcours = cycle hamiltonien.

Invariant : Signature

Chaque cycle a une signature de pas : les sauts entre sommets consécutifs.

Ex: {5/2} → pas = (2,2,2,2,2)

Équivalence

Deux cycles sont équivalents si leurs signatures sont égales à rotation ou miroir près.
