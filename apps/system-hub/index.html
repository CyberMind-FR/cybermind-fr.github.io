🎛️ Central Control for OpenWrt

System Hub

Centre de contrôle unifié avec gestion des composants, rapports de santé automatisés, assistance remote RustDesk et collecte de diagnostics.

⬇️ Télécharger 🎮 Voir la Démo

✨ Fonctionnalités

🧩

Gestion des Composants

Vue unifiée de tous vos dashboards et services. Start, Stop, Restart en un clic.

💚

Rapports de Santé

Score global 0-100, métriques détaillées, seuils configurables, recommandations.

🖥️

Assistance RustDesk

Support à distance sécurisé avec ID unique, approbation requise et timeout.

🔍

Diagnostics

Collecte automatisée des logs, configs et infos réseau. Anonymisation incluse.

📋

Logs Unifiés

Agrégation de tous les logs composants avec filtres et export CSV.

📅

Automatisation

Tâches planifiées : health check, backup, nettoyage logs automatiques.

📦 Installation

# Prérequis
opkg update
opkg install luci-base rpcd

# RustDesk (optionnel)
opkg install rustdesk

# Cloner et installer
git clone https://github.com/gkerma/luci-app-system-hub.git
cd luci-app-system-hub && make install

# Redémarrer
/etc/init.d/rpcd restart
