# 🎨 Hexo Theme CyberMind

> Thème Hexo moderne avec mode clair/sombre et contenu 100% dynamique.

## ✨ Fonctionnalités

- 🌓 **Mode Clair/Sombre** avec switch et mémorisation
- 📱 **100% Responsive** avec menu hamburger
- 🎯 **Contenu Dynamique** via Markdown
- 🎨 **Personnalisation** via variables CSS

## 📁 Structure du contenu

| Dossier | Contenu |
|---------|---------|
| `source/_posts/` | Articles |
| `source/services/` | Services |
| `source/apps/` | Applications |
| `source/portfolio/` | Portfolio |
| `source/gallery/` | Galerie |

## 🚀 Installation

```bash
cd mon-blog
git clone https://github.com/CyberMind-FR/hexo-theme-cybermind.git themes/cybermind
# Puis dans _config.yml: theme: cybermind
```
