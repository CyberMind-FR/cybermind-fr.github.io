🔥 1. Triade Astrodynamique — Mode Complet

Gémeaux — Le Mental Mutable

  • Qualités : clair, rapide, adaptable
  • Défauts : dispersion, saturation mentale, anxiété
  • Élément : Air
  • Pouvoir : déverrouiller la compréhension
  • Fragilité : doutes

Verseau — L’Esprit Visionnaire

  • Qualités : innovation, futur, idées larges
  • Défauts : détachement, froideur, procrastination
  • Élément : Air supérieur
  • Pouvoir : vision du futur
  • Fragilité : fuite du réel

Poissons — Le Flux Sensible

  • Qualités : intuition, empathie, imagination
  • Défauts : confusion, sur-sensibilité
  • Élément : Eau
  • Pouvoir : synchronicités
  • Fragilité : brouillard émotionnel
