1. Triades Astrodynamiques

  • Gémeaux (Mental Mutable) : clair, adaptable / dispersion, anxiété
    • Pouvoir : compréhension
    • Fragilité : doutes
  • Verseau (Esprit Visionnaire) : innovation / froideur, procrastination
    • Pouvoir : vision du futur
    • Fragilité : fuite du réel
  • Poissons (Flux Sensible) : intuition, imagination / confusion, fatigue
    • Pouvoir : synchronicités
    • Fragilité : brouillard émotionnel

2. Sphères de Vie (Clair / Ombre / Dynamo)

A — Amour : affection / jalousie / geste pur
B — Boulot : efficacité / pression / micro-tâche
C — Corps : vitalité / fatigue / respiration
D — Développement : apprentissage / surcharge / 1 page
E — Expression : message / blocage / 1 phrase
F — Flow Créatif : inspiration / chaos / 1 idée
G — Générosité : don / fuite / 1 acte
H — Habitat : ordre / désordre / 1 objet
I — Intelligence : stratégie / suranalyse / décider
J — Joie : vitalité / vide / 1 plaisir
K — Karma : sens / errance / symbole
L — Lien social : contact / isolement / 1 message

3. Familles du Grimoire Cyber-Opéra

  • Action — produire
  • Pause — ressentir
  • Combat — trancher
  • Initiation — transformer
  • Chaos — brouiller pour révéler

4. Niveaux du Feu Intérieur

Étincelle — Flamme — Brasier — Cendre — Phoenix
Risques :

  • brûler trop vite
  • feu sans direction
  • étouffé par émotions
  • dispersé par mental
  • refroidi par détachement

5. Rituels

  • Tirage quotidien : 1 carte + 4 sphères
  • Scène opératique : 5 cartes
  • Cycle mensuel : Arcane + Sphère + Défaut + Feu + Synchronicité

6. Journal Opéra
