🧿 Légende officielle – Sphères de vie

🔢 Code en haut de la page

  • 31 → nombre de jours max dans un mois
  • 15–16 → objectif : nourrir une sphère 15 à 16 fois dans le mois
  • 12回 → répéter ça sur 12 mois

✅ Quand une sphère atteint 15–16 actions dans le mois, son carré est considéré comme complet.

🔤 Les 12 sphères (lettres dans les cases)

  • A – ❤️ Amour
    Relation de couple, intimité, moments à deux.

  • B – 💼 Business / Boulot
    Projets pros, carrière, mission, création de valeur.

  • C – 🏃 Corps / Santé
    Mouvement, sport, sommeil, alimentation, soins physiques.

  • D – 🌌 Développement perso / Spirituel
    Introspection, rituels, thérapie, méditation, sens.

  • E – 🏡 Environnement
    Maison, rangement, déco, nature, ville, lieux où tu vis.

  • F – 👨‍👩‍👧 Famille
    Temps avec la famille, liens, soutien, présence.

  • G – 💰 Gestion de l’argent
    Budget, revenus, organisation financière, abondance.

  • H – 🧠 Habitat intérieur
    Mental, émotions, état d’esprit, hygiène psychique.

  • I – 🎨 Inspiration / Créativité
    Art, écriture, musique, design, idées folles.

  • J – 🎮 Jeux / Fun / Loisirs
    Détente, jeux, sorties, plaisir pur.

  • K – 📚 Knowledge (Savoirs)
    Apprentissage, études, skills, lectures, formations.

  • L – 🤝 Liens sociaux / Amis
    Amitiés, communauté, réseau, rencontres.

⬜ Les carrés (progression dans le mois)

Pour chaque sphère et chaque mois :

  • ~4 actions → 1ᵉʳ côté du carré
  • ~8 actions → 2ᵉ côté
  • ~12 actions → 3ᵉ côté
  • 15–16+ actions → 4ᵉ côté : carré fermé ✅

Plus le carré est complet, plus la sphère a été nourrie ce mois-ci.

🎨 Code couleurs (optionnel)

  • 🔵 Bleu → actions fluides, “normales”
  • 🔴 Rouge → actions faites dans la difficulté / résistance
  • 🟢 Vert → actions qualitatives, bonus, dépassement

Tu peux :

  • colorer les côtés du carré selon la tendance du mois,
  • ou entourer la lettre en vert quand la sphère a été particulièrement bien nourrie.
