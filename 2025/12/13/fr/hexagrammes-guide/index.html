六十四卦 Les 64 Hexagrammes

Guide de référence des 64 hexagrammes du Yi Jing avec leurs noms, trigrammes et significations principales.

Section I : Hexagrammes 1-8

1. 乾 K’ien - Le Créateur

  • Trigrammes : ☰ Ciel / ☰ Ciel
  • Jugement : Le Créateur opère une sublime réussite, favorisant par la persévérance.
  • Image : Le mouvement du ciel est puissant. Ainsi l’homme noble se rend fort et infatigable.

2. 坤 K’ouen - Le Réceptif

  • Trigrammes : ☷ Terre / ☷ Terre
  • Jugement : Le Réceptif opère une sublime réussite, favorisant par la persévérance d’une jument.
  • Image : L’état de la terre est l’accueil réceptif.

3. 屯 Tchouen - La Difficulté Initiale

  • Trigrammes : ☵ Eau / ☳ Tonnerre
  • Jugement : La Difficulté Initiale opère une sublime réussite. Il est avantageux de persévérer.
  • Image : Nuages et tonnerre : image de la Difficulté Initiale.

4. 蒙 Mong - La Folie Juvénile

  • Trigrammes : ☶ Montagne / ☵ Eau
  • Jugement : La Folie Juvénile a succès. Ce n’est pas moi qui cherche le jeune fou.
  • Image : Au pied de la montagne sort une source.

5. 需 Su - L’Attente

  • Trigrammes : ☵ Eau / ☰ Ciel
  • Jugement : L’Attente. Si tu es sincère, tu possèdes lumière et réussite.
  • Image : Des nuages montent dans le ciel.

6. 訟 Soung - Le Conflit

  • Trigrammes : ☰ Ciel / ☵ Eau
  • Jugement : Le Conflit. Tu es sincère et tu rencontres de l’obstruction.
  • Image : Le ciel et l’eau vont en sens contraires.

7. 師 Che - L’Armée

  • Trigrammes : ☷ Terre / ☵ Eau
  • Jugement : L’Armée a besoin de persévérance et d’un homme fort.
  • Image : Au milieu de la terre est l’eau.

8. 比 Pi - La Solidarité

  • Trigrammes : ☵ Eau / ☷ Terre
  • Jugement : La Solidarité apporte la fortune.
  • Image : Sur la terre est l’eau.

Section II : Hexagrammes 9-16

9. 小畜 Siao Tch’ou - Le Pouvoir d’Apprivoisement du Petit

  • Trigrammes : ☴ Vent / ☰ Ciel
  • Jugement : Réussite. Des nuages épais, pas de pluie.

10. 履 Liu - La Marche

  • Trigrammes : ☰ Ciel / ☱ Lac
  • Jugement : Marcher sur la queue du tigre. Il ne mord pas l’homme.

11. 泰 T’ai - La Paix

  • Trigrammes : ☷ Terre / ☰ Ciel
  • Jugement : Le petit s’en va, le grand vient. Fortune. Succès.

12. 否 P’i - La Stagnation

  • Trigrammes : ☰ Ciel / ☷ Terre
  • Jugement : Des hommes mauvais ne favorisent pas la persévérance de l’homme noble.

13. 同人 T’ong Jen - La Communauté avec les Hommes

  • Trigrammes : ☰ Ciel / ☲ Feu
  • Jugement : Communauté avec les hommes dans la campagne. Succès.

14. 大有 Ta Yeou - Le Grand Avoir

  • Trigrammes : ☲ Feu / ☰ Ciel
  • Jugement : Sublime réussite.

15. 謙 K’ien - L’Humilité

  • Trigrammes : ☷ Terre / ☶ Montagne
  • Jugement : L’Humilité crée le succès. L’homme noble mène à bonne fin.

16. 豫 Yu - L’Enthousiasme

  • Trigrammes : ☳ Tonnerre / ☷ Terre
  • Jugement : Il est avantageux d’engager des auxiliaires et de faire marcher des armées.

Section III : Hexagrammes 17-24

17. 隨 Souei - La Suite

  • Trigrammes : ☱ Lac / ☳ Tonnerre
  • Jugement : Sublime réussite. La persévérance est avantageuse.

18. 蠱 Kou - Le Travail sur ce qui est Corrompu

  • Trigrammes : ☶ Montagne / ☴ Vent
  • Jugement : Sublime réussite. Il est avantageux de traverser les grandes eaux.

19. 臨 Lin - L’Approche

  • Trigrammes : ☷ Terre / ☱ Lac
  • Jugement : Sublime réussite. La persévérance est avantageuse.

20. 觀 Kouan - La Contemplation

  • Trigrammes : ☴ Vent / ☷ Terre
  • Jugement : L’ablution a été accomplie mais non encore l’offrande.

21. 噬嗑 Che Ho - Mordre au Travers

  • Trigrammes : ☲ Feu / ☳ Tonnerre
  • Jugement : Réussite. Il est avantageux de faire valoir la justice.

22. 賁 Pi - La Grâce

  • Trigrammes : ☶ Montagne / ☲ Feu
  • Jugement : Succès. Dans les petites choses il est avantageux d’entreprendre.

23. 剝 Po - L’Éclatement

  • Trigrammes : ☶ Montagne / ☷ Terre
  • Jugement : Il n’est pas favorable d’aller quelque part.

24. 復 Fou - Le Retour

  • Trigrammes : ☷ Terre / ☳ Tonnerre
  • Jugement : Succès. Sortie et rentrée sans faute.

Section IV : Hexagrammes 25-32

25. 無妄 Wou Wang - L’Innocence

  • Trigrammes : ☰ Ciel / ☳ Tonnerre
  • Jugement : Sublime réussite. La persévérance est avantageuse.

26. 大畜 Ta Tch’ou - Le Pouvoir d’Apprivoisement du Grand

  • Trigrammes : ☶ Montagne / ☰ Ciel
  • Jugement : La persévérance est avantageuse. Ne pas manger chez soi apporte la fortune.

27. 頤 Yi - Les Commissures des Lèvres

  • Trigrammes : ☶ Montagne / ☳ Tonnerre
  • Jugement : La persévérance apporte la fortune.

28. 大過 Ta Kouo - La Prépondérance du Grand

  • Trigrammes : ☱ Lac / ☴ Vent
  • Jugement : La poutre faîtière fléchit. Succès.

29. 坎 K’an - L’Insondable

  • Trigrammes : ☵ Eau / ☵ Eau
  • Jugement : Si tu es sincère, tu as du succès dans ton cœur.

30. 離 Li - Ce qui s’Attache

  • Trigrammes : ☲ Feu / ☲ Feu
  • Jugement : La persévérance est avantageuse. Elle apporte la réussite.

31. 咸 Hien - L’Influence

  • Trigrammes : ☱ Lac / ☶ Montagne
  • Jugement : Succès. La persévérance est avantageuse.

32. 恆 Hong - La Durée

  • Trigrammes : ☳ Tonnerre / ☴ Vent
  • Jugement : Succès. Pas de blâme. La persévérance est avantageuse.

Section V : Hexagrammes 33-40

33. 遯 Touen - La Retraite

  • Trigrammes : ☰ Ciel / ☶ Montagne
  • Jugement : Succès. Dans les petites choses la persévérance est avantageuse.

34. 大壯 Ta Chouang - La Puissance du Grand

  • Trigrammes : ☳ Tonnerre / ☰ Ciel
  • Jugement : La persévérance est avantageuse.

35. 晉 Tsin - Le Progrès

  • Trigrammes : ☲ Feu / ☷ Terre
  • Jugement : Le prince puissant est honoré par des chevaux en grand nombre.

36. 明夷 Ming Yi - L’Obscurcissement de la Lumière

  • Trigrammes : ☷ Terre / ☲ Feu
  • Jugement : Dans l’adversité il est avantageux d’être persévérant.

37. 家人 Kia Jen - La Famille

  • Trigrammes : ☴ Vent / ☲ Feu
  • Jugement : La persévérance de la femme est avantageuse.

38. 睽 K’ouei - L’Opposition

  • Trigrammes : ☲ Feu / ☱ Lac
  • Jugement : Dans les petites choses, fortune.

39. 蹇 Kien - L’Obstacle

  • Trigrammes : ☵ Eau / ☶ Montagne
  • Jugement : Le sud-ouest est avantageux.

40. 解 Hiai - La Libération

  • Trigrammes : ☳ Tonnerre / ☵ Eau
  • Jugement : Le sud-ouest est avantageux.

Section VI : Hexagrammes 41-48

41. 損 Souen - La Diminution

  • Trigrammes : ☶ Montagne / ☱ Lac
  • Jugement : La Diminution jointe à la sincérité opère un sublime succès.

42. 益 Yi - L’Augmentation

  • Trigrammes : ☴ Vent / ☳ Tonnerre
  • Jugement : Il est avantageux d’entreprendre quelque chose.

43. 夬 Kouai - La Percée

  • Trigrammes : ☱ Lac / ☰ Ciel
  • Jugement : On doit faire connaître la chose avec résolution à la cour du roi.

44. 姤 Keou - Venir à la Rencontre

  • Trigrammes : ☰ Ciel / ☴ Vent
  • Jugement : La jeune fille est puissante.

45. 萃 Ts’ouei - Le Rassemblement

  • Trigrammes : ☱ Lac / ☷ Terre
  • Jugement : Succès. Le roi s’approche de son temple.

46. 升 Cheng - La Poussée vers le Haut

  • Trigrammes : ☷ Terre / ☴ Vent
  • Jugement : Sublime réussite. Il faut voir le grand homme.

47. 困 K’ouen - L’Accablement

  • Trigrammes : ☱ Lac / ☵ Eau
  • Jugement : Réussite. Persévérance. Le grand homme opère la fortune.

48. 井 Tsing - Le Puits

  • Trigrammes : ☵ Eau / ☴ Vent
  • Jugement : On peut changer de ville mais non de puits.

Section VII : Hexagrammes 49-56

49. 革 Ko - La Révolution

  • Trigrammes : ☱ Lac / ☲ Feu
  • Jugement : En ton propre jour tu seras cru. Sublime réussite.

50. 鼎 Ting - Le Chaudron

  • Trigrammes : ☲ Feu / ☴ Vent
  • Jugement : Sublime fortune. Succès.

51. 震 Tchen - L’Éveilleur

  • Trigrammes : ☳ Tonnerre / ☳ Tonnerre
  • Jugement : L’Ébranlement apporte la réussite.

52. 艮 Ken - L’Immobilisation

  • Trigrammes : ☶ Montagne / ☶ Montagne
  • Jugement : L’Immobilisation du dos, de sorte qu’il ne sent plus son corps.

53. 漸 Tsien - Le Développement

  • Trigrammes : ☴ Vent / ☶ Montagne
  • Jugement : La jeune fille est conduite à son époux. Fortune.

54. 歸妹 Kouei Mei - L’Épousée

  • Trigrammes : ☳ Tonnerre / ☱ Lac
  • Jugement : Des entreprises apportent l’infortune.

55. 豐 Fong - L’Abondance

  • Trigrammes : ☳ Tonnerre / ☲ Feu
  • Jugement : Succès. Le roi l’atteint. Ne sois pas triste.

56. 旅 Liu - Le Voyageur

  • Trigrammes : ☲ Feu / ☶ Montagne
  • Jugement : Succès par la petitesse.

Section VIII : Hexagrammes 57-64

57. 巽 Souen - Le Doux

  • Trigrammes : ☴ Vent / ☴ Vent
  • Jugement : Succès par ce qui est petit.

58. 兌 Touei - Le Joyeux

  • Trigrammes : ☱ Lac / ☱ Lac
  • Jugement : Succès. La persévérance est avantageuse.

59. 渙 Houan - La Dissolution

  • Trigrammes : ☴ Vent / ☵ Eau
  • Jugement : Succès. Le roi s’approche de son temple.

60. 節 Tsie - La Limitation

  • Trigrammes : ☵ Eau / ☱ Lac
  • Jugement : Succès.

61. 中孚 Tchong Fou - La Vérité Intérieure

  • Trigrammes : ☴ Vent / ☱ Lac
  • Jugement : Des porcs et des poissons. Fortune.

62. 小過 Siao Kouo - La Prépondérance du Petit

  • Trigrammes : ☳ Tonnerre / ☶ Montagne
  • Jugement : Succès. La persévérance est avantageuse.

63. 既濟 Ki Tsi - Après l’Accomplissement

  • Trigrammes : ☵ Eau / ☲ Feu
  • Jugement : Succès dans les petites choses. Au commencement fortune, à la fin troubles.

64. 未濟 Wei Tsi - Avant l’Accomplissement

  • Trigrammes : ☲ Feu / ☵ Eau
  • Jugement : Succès. Mais si le petit renard met la queue dans l’eau, il n’est rien qui soit avantageux.
