🔒 Enigmabox / OpenWrt — Financement participatif

Infrastructure réseau souveraine • Firmware OpenWrt custom • Overlay chiffré multipoint

Nous finalisons une pile réseau complète : firmware OpenWrt modifié, protocole d’identité distribué, overlay router sécurisé et CI/CD reproductible.
Votre soutien rend possible le passage en production. 🚀

🎯 Objectifs Techniques (résumé hardcore)

  • 🛠️ Firmware OpenWrt
    Patches kernel, build ARM/MIPS/x86_64, packaging Enigmabox services.

  • 🔐 Overlay sécurisé
    Chiffrement E2E (X25519 / ChaCha20 / Poly1305), auto-routing multipoint, enigmad, identity-manager, overlay-router.

  • ⚙️ CI/CD reproductible
    Builds déterministes, signatures officielles, serveurs redondants, tests automatisés.

  • 📚 Documentation & API
    Specs protocolaires, diagrammes d’architecture, guides dev & offline-first.

💰 Allocation des Fonds

  • 45% — 🧪 Dev logiciel & kernel
