Devices & EnigmaBox Suite

Les images générées par le système de build OpenWRT sont destinées aux différents appareils de l’EnigmaBox Suite.

Device : EnigmaBox Suite

Fonctions principales :

  • routeur chiffré
  • mesh overlay (CJDNS, etc.)
  • services sécurisés embarqués

Qualité & Priorités

Icônes visibles sur le schéma indiquent des priorités :

  • 💲 Coûts
  • ✳️ Qualité / stabilité
  • ⚠️ Risques / sécurité
  • 🎲 Expérimental / aléatoire

Chaque release est classée selon ces critères afin d’aider les développeurs et testeurs.

Objectifs

  • Images stables et reproductibles
  • Support long terme
  • Modules customisés pour les besoins Enigma
