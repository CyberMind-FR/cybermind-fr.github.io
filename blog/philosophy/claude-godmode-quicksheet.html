🌀 Les 3 Niveaux de Récursion Utiles

✅Niveau 1: Auto-Critique Simple
Réponds, puis demande-toi: "Qu'est-ce qui est faible dans cette réponse?"

🎯 Point fixe: 1 itération suffit pour 80% des cas

✅Niveau 2: Simulation d'Expert
Réponds comme si [Gandalf senior / auditeur ANSSI] allait relire et critiquer. Intègre ses objections probables.

🎯 Point fixe: L'expert simulé n'a plus rien à dire

⚠️Niveau 3: Meta-Pattern
Observe tes patterns de réponse sur [N] échanges. Quels réflexes sont devenus des béquilles? Casse-les volontairement.

🎯 Point fixe: Quand le changement améliore vraiment, pas juste innove

❌Niveau 4+: Éviter

RÈGLE: Si 3 boucles n'améliorent plus, STOP et livre.

🛡️ Sécurité & SecuBox

🔐 Audit Config OpenWrt

Analyse cette config UCI comme un auditeur ANSSI. Checklist: firewall rules, services exposés, credentials, logging. Sortie: tableau [finding | criticité | remediation | ref CIS].

🐝 Règles CrowdSec

Crée un scenario CrowdSec pour détecter [pattern d'attaque]. Format YAML complet avec: filter, groupby, blackhole, labels. Teste sur ces logs samples: [logs]

📋 Documentation Certif

Rédige une section [X] du dossier de validation pour [ANSSI/BSI/CISA]. Style: formel, référencé ISO27001, preuves factuelles. Inclus: objectif, mesures, preuves, écarts, plan de remédiation.

🎯 Formules Récursives Prêtes à l'Emploi

🔁 Le Triple Miroir (Universel)

[Requête]. Réponds. Critique ta réponse (3 faiblesses max). Version finale intégrant les corrections. Montre UNIQUEMENT la finale sauf si je demande le processus.

🐍 L'Ouroboros Créatif

Génère [contenu créatif]. Puis: "Si ce texte était un hexagramme, lequel serait-il?" Utilise cette métaphore pour identifier sa ligne mutante. Transforme cette ligne.

🔐 Le Pentest de Soi

Propose [solution/architecture/argument]. Puis attaque-la comme un adversaire intelligent. Puis défends-la en intégrant les attaques valides. Livre la version durcie.

⚖️ Le Point Fixe Forcé

Itère sur [tâche] jusqu'à ce que deux versions consécutives soient quasi-identiques. C'est ton point fixe. Livre-le. Maximum 5 itérations (sinon: paralysie).
