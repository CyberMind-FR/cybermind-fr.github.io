// Architecture

Plateformes Supportées

Compilation automatique pour toutes les architectures OpenWrt majeures via GitHub Actions

ARM 64-bit (AArch64)

  • aarch64-cortex-a53 (ESPRESSObin, BananaPi R64)
  • aarch64-cortex-a72 (MOCHAbin, RPi 4, NanoPi R4S)
  • mediatek-filogic (GL.iNet MT3000)
  • rockchip-armv8 (NanoPi R5S, FriendlyARM)
  • bcm27xx-bcm2711 (Raspberry Pi 4)

ARM 32-bit

  • arm-cortex-a7-neon (Orange Pi, Allwinner)
  • arm-cortex-a9-neon (Linksys WRT, Turris Omnia)
  • qualcomm-ipq40xx (Google WiFi, Zyxel)
  • qualcomm-ipq806x (Netgear R7800)

MIPS

  • mips-24kc (TP-Link Archer, Ubiquiti)
  • mipsel-24kc (Xiaomi, GL.iNet, Netgear)
  • mipsel-74kc (Broadcom BCM47xx)

x86

  • x86-64 (PC, VMs, Docker, Proxmox)
  • x86-generic (Legacy PC, Atom)
